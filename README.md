# Owen Pritchard — Project Portfolio

Live site: https://proj-v-op.github.io

Hand-coded static site (HTML/CSS/JS, no build step) served by GitHub Pages.

- `projects/` — simulation, drone, and CAD pages
- `code/msdsim/` — 3D mass-spring-damper solver (Python, NumPy/SciPy)
- `code/blackbox/` — Betaflight Blackbox log analysis
- `cad/` — SolidWorks files and screenshots
- `assets/` — images and video

Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000
